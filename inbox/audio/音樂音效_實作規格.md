# 渡鴉下潛：音樂與音效實作規格（音樂大師）

所有檔案都在 `inbox/`，MP3 128k、44.1 kHz。播放音量一律用 1.0，音量差已經在檔案裡調好。

## 播放方式
- 所有循環一律用 Web Audio 的 `AudioBufferSourceNode`，設定 `loop=true`、`loopStart=0`、`loopEnd`=下表秒數。不要用 `<audio loop>`，MP3 的編碼補白會讓接縫出現空隙。
- 背景音樂和環境底噪各用一個音軌（GainNode）同時播放，換場時各自淡入淡出 1～2 秒。
- 背景音樂的音軌後面接一個 BiquadFilter（lowpass，平常設 20000 Hz），完全非人形態時降到約 600 Hz。

## 三相對應的聲音
- 人形：正常播放。
- 半妖：疊上音量約 0.3 的 amb_dive3 低語，背景音樂的 playbackRate 設 0.97。
- 完全非人：低通濾波降到 600 Hz，加上心跳循環；結束時播 sfx_recall，再把濾波打開。

## 怪物陣營音效（敵人資料加一個 `fac` 欄位：eldritch／xian／flesh）
| 檔名 | 時機 |
|---|---|
| sfx_mon_<fac>_appear | 敵人登場 |
| sfx_mon_<fac>_atk | 敵人攻擊（玩家被打時，跟 sfx_hit 一起疊播） |
- eldritch（不可名狀）：不和諧的低鳴、倒放的耳語、濕黏的觸手聲
- xian（詭異中式修仙）：走音的寺鐘、木魚、符紙燒起來的聲音
- flesh（血肉機械）：齒輪磨擦、活塞、濕肉的擠壓聲

## 怪物三系的機制音效（對應 rules_v0.6_怪物三系）
| 檔名 | 時機 |
|---|---|
| sfx_breakthrough | 修仙系：境界滿 3 層突破 |
| sfx_reveal | 不可名狀系：打中後揭露「？」意圖 |
| sfx_part_break | 血肉機械系：拆掉一個零件；縫回去時用同一個檔案，playbackRate 設 0.7 |
層與流派對應：第一層 xian、第二層 eldritch、第三層 flesh，所以 amb_dive1～3 不用換。

## 怪物三系・死亡音效（v0.4 追加）
三系各有自己的倒下聲，用來取代通用的 `sfx_kill`（通用的留給沒有 `fac` 的敵人）。每支長 1.6 秒，最後 0.4 秒是殘響尾巴，可以跟下一個音效疊著播。
- `sfx_mon_eldritch_die`：叫號機的三聲提示，第四聲沒響，然後沉進水底。
- `sfx_mon_xian_die`：誦經慢慢走調，木魚少敲一下，最後一聲走音的鐘，之後全然安靜。
- `sfx_mon_flesh_die`：齒輪慢慢停下來，靜了一下，在 0.95 秒抽搐最後一次，然後停住。不做爆炸解體。
觸發：敵人 HP 歸零時，依 `fac` 播放對應的那一支。

## 慾望契與新增本源（v0.5 追加）
**慾望契音效**：立契時播放一次，每支 1.8～2.1 秒。前段是該慾望自己的聲音，結尾統一是一筆筆刷加一聲落印，表示契約生效。代價觸發時（例如「貪」進商店讓異化值 +10）不另做新音效，沿用 `sfx_corrupt`。
| 檔名 | 慾望 | 聲音 |
|---|---|---|
| `sfx_pact_greed` | 貪 | 銅錢傾瀉，最後一枚一直轉，越轉越慢 |
| `sfx_pact_glutton` | 饞 | 濕的咀嚼三下、吞嚥、胃裡低鳴 |
| `sfx_pact_grudge` | 怨 | 弓擦弦，兩條不和諧的音一路往上爬 |
| `sfx_pact_obsess` | 執 | 絲線吱嘎重複同三個音，一次比一次緊 |
| `sfx_pact_vanity` | 艷（虛榮） | 鏡面的微光，收尾一聲扇子合上 |
| `sfx_pact_pride` | 傲 | 一聲低鑼，上面一個冷的高音，沒有回應 |
| `sfx_pact_envy` | 嫉 | 兩個差一點的玻璃音互相拍打，加倒放低語 |
| `sfx_pact_wrath` | 怒 | 悶擊、碎玻璃、低吼（對應 `yx_desire_wrath`，如果規則不做怒，可以不用） |
慾望的 key 由規則定稿；如果命名不同，對照表照上面中文對應改名即可。

**本源型態層 M08～M12**（出牌時疊在出牌音上，用法跟 `sfx_form_B01` 等相同）：
- `sfx_form_M08` 水母：玻璃般的柔和脈動
- `sfx_form_M09` 鮟鱇：一聲誘燈的高音，底下是深處的顎
- `sfx_form_M10` 蛾：拍翅加細小的火星
- `sfx_form_M11` 珊瑚：脆的骨花碰撞聲
- `sfx_form_M12` 寄生藤：藤蔓爬動、絞緊的吱嘎
目前已有型態層的本源：B01、M01、M02、M03、M08～M12。其他本源（B02～B11、M04～M07）尚未做，先用 B01 或不疊。

**慾望契 id 已和 rules v0.7 對齊**（greed／glutton／grudge／obsess／vanity／pride／envy／wrath），檔名 `sfx_pact_<id>`，所以也可以直接用資料欄位 `sfx:'sfx_pact_'+id`。

**克勞德的心願**：立願時播放，聲音溫暖、乾淨、非性，結尾是燈火輕晃，不用落印。檔名 `sfx_wish_<id>`：
- `sfx_wish_home` 想回家：音樂盒的小旋律，加一聲輕輕關上的門
- `sfx_wish_letter` 想把信寄出去：摺紙聲，接著拍翅聲
- `sfx_wish_guard` 想保護家人：溫暖、穩定的低音慢慢鋪開
- `sfx_wish_remember` 想記住每一個人：輕聲數著音符
