## 四、十戒全開

條件：同一局十枚全亮。之後下一次異化值到 100，合相改成「十戒全開」，持續 3 回合，取代合相原本的 2 回合。若十枚全亮時異化值已經是 100，先照常喚回，等下一次再到 100 才觸發。每局最多發動一次。進場時，牌組裡的十張戒指牌全部放進手牌，這 3 回合手牌上限不算，費用 0。三張臉的修正同時生效。

結算順序固定，從左手無名指的渡鴉之鎖開始：`devotion` → `pride` → `envy` → `obsess` → `cruelty` → `greed` → `wrath` → `sweetmalice` → `vanity` → `glutton`。每枚戒指的被動或連動，每回合最多觸發一次。`vanity` 再打一次的那張牌不會再觸發 `vanity`。`glutton` 的效果不會被 `obsess` 再加強。

音效建議先用合相的 `sfx_merge`。若音樂大師另做專用音效，再換。

### 開場

### 每回合開始（共 3 回合）

第 1 回合　yy:all：十戒全開，第 1 回合。打出戒指牌，之後打出的戒指牌傷害和格擋各加 2，最多加到 18。
第 2 回合　yy:all：十戒全開，第 2 回合。連動還在。傷害和格擋繼續往上加，最多加到 18。
第 3 回合　yy:all：十戒全開，最後一回合。這回合結束後，喚回照常發動。

### 連動層數（畫面上的字）

名稱：十戒連動
說明：這 3 回合裡，每打出一張戒指牌，之後打出的戒指牌傷害和格擋各 +2。可疊加，最多 +18。第一張不加。打到第十張時，那一張是 +18。
沒打出戒指牌時不顯示。
打出第 1 張之後顯示：連動 +2
之後依序：連動 +4、連動 +6、連動 +8、連動 +10、連動 +12、連動 +14、連動 +16、連動 +18
到 +18 就停，不再往上加。
狀態列短句：已疊 {n} 層，傷害和格擋各 +{v}，最多 +18。

沒有傷害、也沒有格擋的戒指牌打出時，連動層數照樣加 1。規則寫的是「每打出一張戒指牌」。十戒全開的 +2 只加在傷害和格擋上，不加在回血上。

## 給克勞德的實作備註

1. 十張牌 id 用 `yy_r_<慾望契 id>`。卡圖 `ring_<id>`。稀有度 `ring`，不能刪、不能變。慾望契加 `img` 欄位接到 `y_desire_<id>` 的事仍照上一封信，和這十張戒指牌不是同一張圖。
2. 任何一枚亮起就往牌組加一張對應的戒指牌，一局一枚只加一次。開局亮的那枚，開局就加。
3. 同一局亮 5 枚：播「半掌」，全部戒指牌升級。同一局十枚全亮：播「十指十色」，給卡背 `cb_rings`；之後下一次異化值到 100，合相改成十戒全開 3 回合。
4. 十戒全開進場：十張戒指牌全部入手，費用 0，這 3 回合手牌上限不算，三面修正同時生效。連動層數用上面的畫面字。結算順序從 `devotion` 開始，按第四段的名單走。`vanity` 再打的那張不會再觸發 `vanity`；`glutton` 不被 `obsess` 再加強。
5. 結束後喚回主句「姐姐，看我。是我。」不要改。深潛 20 若這次喚回已經用掉，改播 `recall20.denied`。
6. 前臉修正和三相按規則第三段套，不要為戒指牌另寫 `fc`。
