# v0.4.1 改動（檔案：`渡鴉下潛_文字劇情_v0.4.1.js`；v0.4 原檔保留不動）
1. **異化值定案**：人形 0～39、半妖 40～99（60 起語熙醒來）、完全非人只在 100。單一本源維持 1 回合，混合型態維持 3 回合，結束後歸 0。`ALIEN` 的 key 改成 s0/s40/s60/s100。冷卻用「收斂」，往上推用「放任」。

3. **新說話者 key**：`ry` 是渡鴉（只出現在 RETURN_AFTER_BEAST），`gu` 是顧沉舟；`yx` 可以用 laugh／fang／sneer 三種表情。
4. **新增區塊**：
   - `FORM_STAGES`：18 個本源 × 人形、半妖、完全非人
   - `STAGE_PAGES`：54 頁
   - `CL_CALLBACK`：4 句聲音，另加語熙掌身局沒有喚回時的一句
   - `RETURN_AFTER_BEAST`：3 組
   - `STAGE_NPC`：事件 NPC、店主、敵人各 3 階段×3 句，加上逃跑 3 句和三相時裝 1 句

## 六、欲望契的來源說明
世界書 A07-01 的七欲是「性慾、食慾、色慾、虐殺欲、惡慾、貪慾、執念」。其中性慾、虐殺欲，還有色慾的原意都不能用。遊戲版保留其中 4 項：貪、饞（食慾）、怨（惡慾）、執（執念）。另外 3 項換成非性的：艷（只取色慾裡「執著完美外表」的虛榮）、傲、嫉。id 依序是 greed、hunger、vanity、grudge、obsession、pride、envy。
