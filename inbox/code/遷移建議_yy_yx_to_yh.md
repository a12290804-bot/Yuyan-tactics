# 語凰嫣遷移建議：`yy`／`yx` → `yh`（給 Claude）
依據：`hex/core.js`、`hex/data.js` v0.25（測試 86/86）。我只提建議，不動主線。

## 0. 原則：只換「角色代號」，不換「資料 id」
- `st.ch`、`D.chars`、meta 裡以角色為鍵的欄位，改成 `yh`。
- 牌、圖、音效的 id **全部不改**（`yy_*` 牌、`y_skin_*`、`yx_ex_*`、`sfx_pact_wrath`…）。這些只是名字，改了會同時弄斷存檔裡的牌組、收藏 `col`、成就、圖檔和測試。
- 用一張對照表決定「這張牌屬於誰」：`ch:'yy'` 175 張和 `ch:'yx'` 6 張，在讀資料時都視為 `yh`，不用一張一張改 data.js。

## 1. core.js：先收口，再換
現在已經有兩個收口函式：`isYY(st)` 和 `baseCh(st)`（第 61–62 行），但還有大約 31 處直接寫 `'yx'`、`ch==='yx'?'yy':ch`。
1. 先把這些都改成呼叫 `isYY`／`baseCh`／新的 `chKey(ch)`，**行為不變**，跑測試要 86/86。
2. 第二步才讓 `chKey('yy')`、`chKey('yx')` 都回傳 `'yh'`，再讓 `isYY` 認 `yh`。
需要特別看的幾處：
- `addAlien`／`case 'al'`：語熙的異化下限 40、起始 60，還有 `fullEnd`／`recall` 的分支。語凰嫣要用規則大師定的新數值（目前提案是起始 60、下限 60、合相不喚回），寫成 `D.chars.yh.alienMin`、`alienStart`，不要再寫死。
- 第 315 行的同體宿敵作亂（`D.sisters`、`meddled`、fog/cold/bitter 與 heart/shake/sneer 兩組）：三面輪替會取代它，建議整段換成「後面那張臉作亂」，舊的 `flags.yx`、`yxWake` 事件移除。
- 第 370 行語熙的爆破、第 526 行 `D.duo` 的織網：變成熙面、嫣面的效果。
- `pool()`（220 行）：`nw` 的判斷加上 `yh`，牌池同時收原本 `yy`／`yx` 的牌，再依當前的臉篩選。
- `metaUnlock` 的 `kind==='char'`（828 行）：`yx` 這個解鎖要拿掉（見第 3 節的退款）。

## 2. 卡牌變化：照污染的做法做
`cardDef(D,x)` 已經會依 `pl`（污染階）改名字和效果。三面也照這個做：`cardDef(D,x,face)`，`face` 是 `h`（凰）／`y`（嫣）／`x`（熙）／`m`（合相）。資料只多一個可選欄位，例如 `faces:{h:{fx:...},x:{c:...}}`，沒寫的就沿用原本。
順序建議：先算臉，再算污染，最後算費用（`cost`）。要加一組測試：同一張牌四種臉的 `fx`＋`c` 要四種都不同（照 C80「每階不同」的寫法）。

## 3. 舊存檔
存檔鍵沿用 `METAK`／`RUNK`。現有 `dive_backup_ver` 備份機制很好，遷移前一定要先寫一份。
### meta（`migrateMeta`）
現在的 `migrateMeta` 只補欄位，`v` 寫死 2。建議改成 `v:3`，從 2 升到 3 時做一次：
- `prof.yy` 和 `prof.yx`：合成 `prof.yh`。`xp`、`pts` 相加，`spent` 取聯集。
- `pol.yy` 和 `pol.yx`：`pol.yh` 取**較大值**（污染只往下，不能讓玩家因為合併而變乾淨）。
- `wins.yy`＋`yxWins` 相加成 `wins.yh`；`yxRuns` 加到 `runs` 的角色統計。刪掉 `yxRuns`／`yxWins`。
- `meta.yx`（花 150 殘響解鎖的語熙）：角色不見了，**退回 150 殘響**，並給一個成就或提示說明。
- `oBuy` 裡 `yy_B11` 這類本源購買：鍵改成 `yh_B11`，或在查詢時用 `chKey` 對照（比較安全，選後者）。
- 成就 `win_yy_<本源>`、`win_yx`：**保留原 id 不改**，另外在 UI 上把它們顯示成語凰嫣的成就。
- `skins` 的 `yy_*`：保留，`yh` 可以穿。
- 個性、慾望、癖好的熟練度 `tm`：以標籤為鍵，不用動。語熙專屬個性（如 `bratmouth`、`usurp`，`ch:'yx'`）改成 `yh` 可用。
### 正在進行的一局（`migrateRun`）
- `s.ch` 是 `yy` 或 `yx` 時改成 `yh`，`s.v` 升到 3。
- 牌組不用動，因為牌 id 沒改。
- 若存檔停在戰鬥中：照 v2 的做法，退回到這場戰鬥開打前重新開打（`startCombat`），不要硬接舊的同體宿敵狀態。
- `alien` 套新的下限：低於 `D.chars.yh.alienMin` 就拉到下限。
- 如果遷移失敗，就丟掉這一局、保留 meta，跳提示，不要讓整個遊戲讀不進來。

## 4. 測試

- 新增遷移測試：拿一份 v0.25 的 meta（有 `prof.yy`、`prof.yx`、`pol.yy`=150、`pol.yx`=200、`meta.yx`=1、`yxWins`=2）跑 `migrateMeta`，檢查 `prof.yh` 合併、`pol.yh`=200、殘響 +150、`wins.yh` 相加，且再跑一次結果不變（遷移要能重複執行）。
- 新增一份 `ch:'yx'`、停在戰鬥中的 run 存檔，`loadRun` 後要是 `yh`、在戰鬥開始前。
