# 卡牌文字排版修正 v0.29（給 Claude 實作）

我只交修正檔，不動 `hex/`。兩個檔案直接貼進 `hex/index.html` 就能用，不用改 `cardHtml`：

1. `卡牌文字排版修正_v0.29.css`：貼在 `index.html` 最後一個 style 區塊的結尾，要排在第 513–534 行那批 `html body .card` 規則之後。
2. `卡牌文字排版修正_v0.29.js`：用 script 標籤放在 core.js 之後、body 結束之前。

## 原本重疊的地方（112×162 的牌）
- 效果文字 12px、行高 1.4（第 513 行），一行只放得下 8 個字。超過 40 字的牌有 685 張，在 2105 張裡全部被截斷。
- 牌名可以換行，第二行壓到效果文字上（例如「妳的不堪我都知道」）。
- 位階徽章在 top 60–62px、高 22–26px，蓋住牌名中間。
- 「長按看全部」、寶石和染度標籤都放在 bottom 2–3px，疊在同一處。慾望註記在 bottom 16px，壓住效果文字。

## 修正後
- 牌名不換行，JS 依寬度從 13px 逐步縮到 9px；仍放不下才顯示省略號。實測 0 張需要省略。
- 效果文字預設 11px，放不下就每次縮 0.5px，最小 9px。還放不下，就把卡圖從 74px 縮成 56px、牌名上移，讓效果區多 18px，再從 10px 縮到 8px。8px 仍放不下才在底部淡出，長按照舊看全文。
- 位階徽章改成底邊貼著牌名上緣，整顆放在卡圖上。
- 底部留一條 14px 的資訊列：「長按看全部」靠左、寶石置中（長文牌靠右）、染度靠右。慾望註記改成貼在效果區上方的單行。

## 實測（headless Chrome，全部 2105 張）
- 效果文字 11px 有 923 張，9px 有 398 張，8px 有 154 張；其他介於中間。
- 縮短卡圖的有 510 張。8px 仍需淡出的只剩 20 張，原本是 685 張。
- 牌名省略 0 張，各元素重疊 0 處。
- 對照圖：`卡牌排版_修正前.png`、`卡牌排版_修正後.png`。

## 注意
- 註解裡不能寫出 style 的結束標籤，否則樣式表會提早結束。檔案裡已經避開。
- 隱藏畫面裡的卡（寬度 0）會先跳過，等它出現後的下一次 DOM 變動或點擊再量。也可以在換畫面後手動呼叫 `fitCardText()`。
- 如果 Claude 想改成在 `cardHtml` 裡直接加字數等級的 class，也可以，但 JS 量實際高度比較準：不同字型和全形符號的寬度都不一樣。
