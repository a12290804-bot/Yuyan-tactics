# 語凰嫣遷移建議：`yx` 併進 `yy`（給 Claude）
依據：`hex/core.js`、`hex/data.js` v0.25（測試 86/86），規則照 `inbox/rules/rules_v0.9_語凰嫣融合.md`。我只提建議，不動主線。

## 0. 原則
- 語凰嫣**沿用 `yy`**，不開新代號。`D.chars.yy` 改名字、立繪（`y_base`）和數值；`D.chars.yx` 拿掉，不能再選。
- 牌、圖、音效的 id **全部不改**（`yy_*`、`yx_*` 牌、`y_skin_*`、`yx_ex_*`、`sfx_pact_wrath`…），舊牌組、收藏 `col`、成就和測試才不會斷。
- 原本 `ch:'yx'` 的牌（含 89 張語熙牌、語熙專屬個性）在讀資料時都視為 `yy` 可用，不用一張一張改 data.js。

## 1. core.js：先收口，再換
已經有兩個收口函式 `isYY(st)`、`baseCh(st)`（第 61–62 行），但還有大約 31 處直接寫 `'yx'` 或 `ch==='yx'?'yy':ch`。
1. 先把這些都改成呼叫 `isYY`／`baseCh`，**行為不變**，跑測試要 86/86。
2. 第二步讓 `baseCh` 永遠回傳 `yy`，再把只屬於語熙的分支換成 v0.9 的三面規則。
要特別看的幾處：
- `addAlien`／`case 'al'`：語熙的異化下限 40、起始 60，以及 `fullEnd`／`recall` 的分支。改用 v0.9 的數值，寫成 `D.chars.yy` 的欄位，不要再寫死。
- `flags.yx`、`yxWake`：改成「凰面醒來」（每局異化第一次到 60）。
- 第 315 行的同體宿敵作亂（`D.sisters`、`meddled`）：換成 v0.9「後面的臉搶一張手牌」。
- 第 370 行語熙的爆破、第 526 行 `D.duo` 的織網：分別變成熙面、嫣面的效果。
- `pool()`（220 行）：牌池同時收原本 `yy`、`yx` 的牌，再依當前的臉篩選。
- `metaUnlock` 的 `kind==='char'`（828 行）：`yx` 這個解鎖拿掉，改成第 3 節的補償。

## 2. 卡牌變化：照污染的做法做
`cardDef(D,x)` 已經會依 `pl`（污染階）改名字和效果。三面也照這個做，例如 `cardDef(D,x,ctx)`，`ctx` 帶當前的臉（`yan`／`xi`／`huang`）和相位，合相是第四種。資料只多一個可選欄位，例如 `faces:{xi:{fx:...},huang:{c:...}}`，沒寫的就沿用原本。v0.9 說的「9 種版本」就是三張臉乘三個相位。
計算順序：先臉，再相位，再污染，最後費用（`cost`）。要加一組測試：同一張三面牌在三張臉下 `fx`＋`c` 都不同（照 C80「每階不同」的寫法）。

## 3. 舊存檔
存檔鍵沿用 `METAK`／`RUNK`。遷移前一定先用現有的 `dive_backup_ver` 寫一份備份。
### meta（`migrateMeta`）
現在的 `migrateMeta` 只補欄位，`v` 寫死 2。改成 `v:3`，從 2 升到 3 時做一次：
- `prof.yx` 併進 `prof.yy`：`xp`、`pts` 相加，`spent` 取聯集，然後刪掉 `prof.yx`。（現在 `profOf` 已經把 yx 導到 yy，多數存檔裡可能本來就沒有 `prof.yx`。）
- `pol`：`pol.yy` 取兩者**較大值**。污染只往下，不能讓玩家因為合併而變乾淨。
- `yxWins` 加進 `wins.yy`，`yxRuns` 加進角色局數；然後刪掉這兩個欄位。
- `meta.yx`（花 150 殘響解鎖的語熙）：**使用者決定送一套語凰嫣的衣服，不退殘響。** 有 `meta.yx` 的存檔，在 `meta.skins` 加上那套衣服的 id，跳一次提示，再刪掉 `meta.yx`。衣服的 id 和圖等製圖大師出圖後再定。
- `oBuy`（`yy_B11` 等）、`skins`（`yy_*`）、成就（`win_yy_<本源>`、`win_yx`）：id 都不改，直接沿用。`win_yx` 在介面上改顯示成語凰嫣的成就。
- 個性、慾望、癖好的熟練度 `tm`：以標籤為鍵，不用動。
### 正在進行的一局（`migrateRun`）
- `s.ch==='yx'` 改成 `yy`，`s.v` 升到 3。牌組不用動。
- 存檔停在戰鬥中：照 v2 的做法，退回這場戰鬥開打前重開（`startCombat`），不要硬接舊的同體宿敵狀態。
- `alien` 套新的下限。
- 遷移失敗就丟掉這一局、保留 meta、跳提示，不要讓整個遊戲讀不進來。
