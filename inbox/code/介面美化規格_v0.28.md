## 〇、現在畫面的問題（依實際程式）

1. **CSS 疊了四層。** `:root` 寫了三次。一開始是 `--bg:#120f0d`、`--gold:#d8b46a`，v0.13 改成 `--bg:#0c0a09`、`--gold:#d6b26a`，後面還有 `--mx`／`--my`。`button.main` 先是褐金，隨後被改成血紅。`.pill` 先是圓角 14px，後來改成 3px。v0.15、v0.16、v0.19、v0.20、v0.24 都在檔案尾巴加補丁，同一條規則被蓋來蓋去。不要再往下疊第五層，先把變數收成一套。

2. **字太小，手機上看不清。** `.card .cd` 10.5px，`.lp` 和 `.plb` 9px，`.pnote` 8.5px，`.gems` 7px。卡面只有 112×162。長說明還靠「長按看全部」，一般出牌時等於看不清。

3. **稀有度看起來扁、而且兩套記號在打架。** 資料裡的位階叫「起始、紙、墨、緋」，外加「契」和「詛咒」（見第三段）。現在同一張牌同時帶 `rk0`–`rk3`／`rko`／`rkx`，又帶 `tier0`–`tier3`，再加上 `tagc`、`fg3`。v0.19 還用銅／銀／金那種通用牌面，名稱條一片平塗黃或平塗藍，加上只有 2px 實線邊，看起來廉價。位階要靠**材質**分辨，不要只換邊框顏色。新的戒指牌用 `rkring`，不要再加一套互相打架的框。

## 二、字體

現在：`"Noto Serif TC","Songti TC","PMingLiU",serif`，並向 `fonts.googleapis.com` 要字。

改成這條，**先用本機 CJK 襯線**，再才是網頁字：

```css
font-family:"Noto Serif TC","Noto Serif CJK TC","Source Han Serif TC",
  "Songti TC","PMingLiU","PingFang TC","STSong","Noto Serif",serif;
```

數字（費用、生命、能量、連動）加 `font-variant-numeric:tabular-nums`。

Google Fonts 改成可選，不要當唯一來源。若要繼續用 Noto Serif TC，請把字體檔放進倉庫自己供（OFL 可免費用），或讓本機已有「Noto Serif CJK TC」的裝置直接用。離線也要看得成字，不能變成沒有中文的襯線體。

卡面說明至少 **12px**，行高 1.4。牌名 13–14px。頂欄、按鈕維持 14–15px。不要再出現 7–9px 的正文。角落小標（染階、寶石點）可以 10px，但必須對比夠（淺字加底，不要淡灰疊暗底）。

## 三、卡框：類型、位階材質、臉、戒指、三面牌

沿用 `cardHtml`（L4151）的結構：`.ci` 圖、`.cc` 費用、`.cn` 牌名、`.cd` 說明、`.rk` 位階名、`.crest` 頂部寶石。不要重做一套 DOM，只整理 class 和 CSS。所有位階都要有層次：外框、內凹黑線、內框、斜角高光、內陰影。邊角加小飾件。牌名是一塊「金屬銘板」，不要平塗色帶。金色一律當成實色金屬，靠高光和倒角，不要整張牌外發光。

### 資料裡真正的位階

`hex/data.js` 第 307 行：

```js
DATA.rarity={
  0:{n:'起始',color:'#5A5A5E'},
  1:{n:'紙',  color:'#A8ADB4'},
  2:{n:'墨',  color:'#2E5E63'},
  3:{n:'緋',  color:'#B08A3E'},
  origin:{n:'契',color:'#8E1B24'},
  x:{n:'詛咒',color:'#2E1A33'}
};
```

卡牌欄位是 `d.r`，數字只有 `0`、`1`、`2`、`3`。畫面用哪個名字，看 `rankOf`（`hex/index.html`）：

```js
function rankOf(d){return d.t==='x'?'x':d.bl?'origin':d.r;}
```

也就是：詛咒（`d.t==='x'`）顯示「詛咒」；有本源欄 `d.bl` 的顯示「契」；其餘用 `d.r` 對到起始／紙／墨／緋。`cardHtml` 已經會加 `rk0`／`rk1`／`rk2`／`rk3`／`rko`／`rkx`。戒指牌在 inbox 裡是 `r:'ring'`，進主線時讓 `rankOf` 在詛咒判斷之後、本源判斷之前加上 `d.r==='ring'?'ring'`，並在 `DATA.rarity` 補 `{n:'戒',color:…}`。`cardHtml` 的 class 用 `rkring`，**不要**重用已經被「語熙圈牌」占用的 `.card.ring`。

三面牌（`yy_f_*`，或帶 `fc`）本身仍有數字位階（規則裡是紙、墨或緋），**材質跟它的 `d.r` 走**，另外再疊三面專用的內框，不要把「三面」做成第五個數字位階。

`tier0`–`tier3` 不要再當另一套「銅銀金」。能併進 `rk*` 就併，免得同一張牌兩套外框互蓋。個性／慾望／癖好的 `tagc` 只留淡紫霧或銘板小標，不要跟位階搶外框。本源「契」繼續可用 `--oc` 微調血色。

### 立體、光、互動

- 框要有斜角：上緣和左緣一條亮線，下緣和右緣一條暗線，再用內陰影把卡心壓進去。
- 極淡的紋理用 CSS 漸層或一張很小的噪音（只蓋在框，不要對整張牌做重濾鏡）。
- 頂部寶石用 `.crest`（現在只有墨、緋才顯示，改成每位階都有，樣子不同）。
- 滑鼠可停時（`@media (hover:hover)`）：牌微微傾斜（`rotateY`／`rotateX`），一層光斑跟著走。現有的 `--mx`、`--my` 可以接到這裡。觸控沒有 hover，點選（`.sel`）只把牌抬高，不要依賴傾斜。
- 緋的掃光：預設就要看得出一層暗虹（靜止截圖也要看得出是閃卡）。滑鼠停上去或選中時，錐形漸層慢慢轉、斜光掃過。用 `@property --foil` 或 `background-position`，不要用很重的 `filter`。
- `prefers-reduced-motion:reduce`：停止所有轉動、掃光、傾斜。緋留下靜止的暗虹層就好。

### 類型、臉、升級

**類型**（`d.t`：`a` 攻擊、`s` 技能、`p` 能力、`x` 詛咒）不要各自做一套卡形。費用球做成金屬幣（有斜角），詛咒除外可以略暗。類型用小標即可。

**三張臉**（規則 v0.9 第二段、外觀全集第 11 節）是**內緣**，不要蓋掉位階外框：

- `face_yan`：內緣紅線 `--face-yan`
- `face_xi`：內緣猩紅，左側一條紅流蘇（CSS 漸層，不要在圖裡燒字）
- `face_huang`：內緣白金 `--face-huang`，實色，不要外發光
- 合相或十戒全開、三面修正同時生效：`face_all`，三色細邊並排，不要閃爍

牌面數字照當下的臉和相即時顯示。長按 `#cdet` 加兩張摺頁或切換，讓玩家看到另外兩張臉的版本。裡側作亂搶走的那張，內緣閃一下對方臉的顏色，閃完回到當前臉；這是一次短動畫，不是一直閃。

升級的牌維持現有 `.cn.up`，或改成銘板上加一道金邊，全遊戲一致即可。

戒指牌不能刪、不能變，這是規則，畫面不必再做刪除鈕。

## 四、污染階段（`polStage` 0–4）

核心已有 `polStage`（0–4）和 `polStage7`（0 起可超過 7）。戰鬥立繪現在用 `.pme.pol2`–`.pol4`；卡面用 `.pl`／`.plv`／`.plx`，跟的是 `polS`（七階制）。玩家會搞混。

畫面統一對外講 **0–4 階**，跟 `polStage`：

| 階 | 畫面 |
|---|---|
| 0 | 沒有額外效果 |
| 1 | 頂欄一個暗金點；卡面幾乎不變 |
| 2 | 立繪略偏紫，卡面邊緣一層薄紫霧（現有 `.card.pl`） |
| 3 | 立繪對比加強，紫霧更重，頂欄污染條開始醒目 |

## 五、敵人意圖，和大招預告句

改 `intentHtml`（L4176），結構改成：

```html
<div class="intent atk">…圖示與數字…</div>
<p class="intent-warn">牠把嘴張到下巴裂開。下回合吞掉妳一張手牌。</p>
```

`.intent-warn` 是給文字劇情大師的**一整句預告**用的槽。沒有預告時不要渲染這個元素，也不要放空白佔位把敵人圖往下擠。句子由資料提供（例如意圖上的 `warn` 欄，欄位名等文字進資料表後再對齊），畫面不要自己編句子。

要求：

- 字 14px 以上，一行可折行，最多兩行，對比要夠。放在意圖吊牌下方、敵人圖上方或緊貼名字上方，不要擋住血條。
- 這句出現的同一瞬間播 `sfx_intent_big`（音樂規格「怪物大招預告」）。
- 點意圖仍可看細節，但不要只靠 1.3 秒的 `flash()`。改成短面板或把意圖名常駐在吊牌裡。
- 看不清的敵人繼續顯示「？」，預告句也先不顯示，直到被打中顯形（維持現有隱藏規則）。
- 攻擊意圖維持紅底吊牌；非攻擊用現有紙紮吊牌。`tagSway` 在減少動態時要停。

## 八、動畫，以及減少動態

可留的短動畫（預設開，約 0.2–0.4 秒）：發牌進入、選牌上移、出牌飛出（現有 `ghostFly`）、受傷數字、意圖出現、換臉框色、戒指點亮。

要收斂的：無限搖擺、無限呼吸縮放、標題不停閃、金卡一直發光、低血時整屏脈搏。留很慢、很小的就好，或只在該畫面剛出現時動一次。

立繪不要用會讓眼睛發亮的濾鏡動畫。

```css
@media (prefers-reduced-motion:reduce){
  *,*::before,*::after{animation:none!important;transition:none!important}
  #bossin,#inkveil,#fxdust{display:none}
}
```

現有的那條 `@media (prefers-reduced-motion:reduce)` 用這條取代，不要並存。`fanHand()` 已經會在減少動態時把弧度收成平排，這段保留。`fxLv()==='low'`（聲音選單裡的特效檔位）繼續當同一條路，少動畫。

## 十、手機和觸控

這是手機優先的遊戲，先顧直向。

- 手牌：5–7 張維持現在的扇形。8–10 張把卡寬收到約 96px、間距縮小，但費用和牌名必須露出來。超過 10 張（十戒全開時一定會遇到）改成兩排，或可橫滑的平底列，**禁止十張疊成一張看不出來**。`#hand` 高度不要寫死 204px，改成依排數變。
- 可點的地方至少 44×44px：結束回合、燈、能量球、意圖、戒指槽。
- 拖曳出牌（現有 pointer 事件）保留，點選也要能出牌。
- `viewport` 拿掉 `user-scalable=no`，改成允許縮放（例如 `maximum-scale=5`）。安全區 `env(safe-area-inset-*)` 已有的地方留下，底欄和頂欄都要算到。
- 橫向：寬度 ≥640px 時，敵人區可以略寬，手牌不必拉滿全寬。渡鴉巷 `#twrap` 現在鎖 720／1280，橫向會很大一塊黑邊，至少讓圖在安全範圍內置中，標籤不要掉到畫面外。
- 觸控不要依賴 `:hover`。現有 `@media (hover:hover)` 的手牌外光可以留，手指點選仍靠 `.sel`。

## 十一、效能

- 手牌不要常駐 `will-change:transform`，只在拖曳或發牌的那幾百毫秒加上。
- `body:after` 只留一層暗角或一層極淡顆粒，不要兩層重疊各算一次全屏。
- 不在畫面裡的 `.scr` 不要還在跑動畫。
- 緋的閃卡用 `background-position` 或 `@property` 轉動錐形漸層，不要對整手牌做 `blur`、重的 `drop-shadow` 或全圖 `filter`。沒出現在畫面裡的閃卡不要動；同一時間在動的閃卡少一點，選中或滑鼠停上去再加強。
- 金卡掃光、意圖搖擺這類無限動畫，同一時間不要超過少數幾個。
- 字體自己供或本機優先，避免每次開啟都等 Google。
- 這次不要為了美化改成 canvas 重畫整場戰鬥，也不要引入大型動畫庫。
