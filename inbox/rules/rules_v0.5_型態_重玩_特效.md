# 渡鴉下潛 規則 v0.5：語嫣 23 型態、克勞德七面、重玩動機、打擊感
疊在 v0.4 上面。v0.4 的第一批 7 套型態不變，這份補齊全部的規則。

## 一、語嫣的 23 型態怎麼在遊戲裡表現
**修正（使用者確認）**：23 指的是「二十三本源」，也就是 12 種妖物（M01～M12）加上 11 種血脈（B01～B11）。世界書 [079] 的 5 種混合型態另外算，不包含在 23 裡面。分成三層來表現：

### 1. 本源型態（23 個，開局選）
每個本源有自己的打法：1 個被動、2 張起始牌、2 張專屬牌（牌邊是「契」的血紅）、1 套時裝。

| 本源 | 打法 | 被動 |
|---|---|---|
| B01 九尾妖狐 | 幻象布局 | 每場第一張攻擊牌給予 1 層厄契 |
| B02 莉莉絲 | 交易與欺騙 | 商店打 8 折；每場戰鬥開始，隨機一個敵人的意圖被看穿（顯示兩回合） |
| B03 拉彌亞 | 蛻皮與等待 | 每 3 回合「蛻皮」：清掉自己所有負面狀態 |
| B04 莎布 | 繁殖 | 打出能力牌時，在手上複製一張 0 費的「孵化」（造成 3 傷害，消耗） |
| B05 奈亞 | 千相偽裝 | 每回合第一張牌可以當成手上另一張牌的複製打出 |
| B06 哈斯塔 | 劇本 | 照「攻擊→技能→能力」的順序打出，第三張免費 |
| B07 鬼新娘 | 紅線婚契 | 被命線連住的敵人死掉時，其他被連住的敵人各失去 8 生命 |
| B08 巫妖 | 命匣保存 | 第一次死亡時回到 30% 生命，命匣碎掉（每局一次） |
| B09 克蘇魯 | 低語錯序 | 抽牌堆頂 3 張永遠看得到，可以花 1 墨換順序 |
| B10 黑山羊 | 獻祭 | 每失去 5 生命，獲得 1 能量（每回合最多 2） |
| B11 渡鴉 | 契約交換 | 通關後解鎖。每場戰鬥可以把一張牌和敵人「交換」意圖一次 |
| M01 毒蛇 | 毒與厄契增長 | 厄契每回合結束 +1（最多 10） |
| M02 蠍子 | 裁定收割 | 用裁定打倒敵人時回復 3 生命 |
| M03 蜘蛛 | 網與命線 | 命線多連 1 回合 |
| M04 血蛭 | 吸血 | 每回合第一次造成攻擊傷害，回復其中 20% |
| M05 蟲族 | 數量 | 造成多段攻擊時，每段多 1 傷害 |
| M06 史萊姆 | 分裂與吸收 | 格擋不會在回合開始全部消失，只少一半 |
| M07 章魚 | 多手 | 每回合多抽 1 張，手牌上限 10 → 12 |
| M08 水母（燈母） | 誘引、麻痺 | 每回合第一個攻擊妳的敵人，下回合力量 -2 |
| M09 鮟鱇（誘燈） | 誘餌 | 每場戰鬥開始放一盞「誘燈」：敵人優先攻擊它（10 生命），它破掉時對所有敵人造成 8 傷害 |
| M10 蛾 | 視野、撲火 | 看得到所有敵人兩回合的意圖；每回合第一次打出技能牌，異化值 +5 |
| M11 珊瑚（骨花） | 堆積、硬化 | 回合結束沒用完的能量，每 1 點變成 4 點格擋，而且這些格擋不會消失 |
| M12 寄生藤（蔓母） | 寄生、持續 | 給予厄契時，同時在敵人身上種 1 層「藤」，每層藤在回合開始讓牠失去 2 生命，並讓妳回 1 生命 |

解鎖：B01 一開始就有，M01～M12 各需 60～200 回憶，B02～B10 是打倒特定首領或達成成就後解鎖，B11 要通關一次。

### 2. 異化值（局內，每場戰鬥都看得到；畫面上叫「外漏」）
- 語嫣有一條「外漏」量表，分 0 到 3 級。自己扣血、抽到詛咒、生命低於一半時都會往上漲，每場戰鬥結束降 1 級。
- 外漏 1：立繪的影子多出尾巴，攻擊牌傷害 +1。
- 外漏 2：對話和卡牌文字偶爾出現錯字或多出來的眼睛，抽牌 +1，但每回合失去 1 生命。
- 外漏 3：「變相」。下一回合她暫時變成當前本源的完全型態，所有牌免費，回合結束失去 8 生命，外漏歸零。
- 這就是世界書裡「人形態也會無意識外漏」的玩法版本，越貪心越強，也越危險。

### 3. 混合型態（5 種，局內的高潮）
一局裡集齊特定的 3 件「殘響遺物」（打倒對應妖物的菁英才會掉），變相時就會變成混合型態，效果比單一本源更強，還有專屬立繪。

| 混合型態 | 需要的殘響 | 變相效果 |
|---|---|---|
| 九尾蜘蛛母體 | 狐、蛛、蟲 | 所有敵人被命線連住，每回合每個敵人 +3 厄契 |
| 深淵蛇蠍巫妖 | 蛇、蠍、巫妖 | 裁定不消耗厄契，傷害 ×1.5 |
| 章魚蟲群深淵母巢 | 章魚、蟲、莎布 | 每打出一張牌，對隨機敵人造成 3 傷害 |
| 鬼狐婚契 | 狐、鬼新娘、莉莉絲 | 回合中被打倒的敵人，下回合為妳戰鬥 1 回合 |
| 巫妖蟲巢收藏者 | 巫妖、蟲、血蛭 | 打倒的敵人變成一張臨時牌加入手牌 |

- 世界書裡的「終相」不做成可以玩的型態，只在最終首領戰的劇情裡出現一次。

## 二、克勞德：絕對的善良，和她的其他面貌
規則上的鐵律：克勞德沒有「殘忍」的選項，她的強來自守護、記住、不放手。她的七面不是黑化，而是善良的不同樣子：

| 面貌 | 她怎麼善良 | 被動 |
|---|---|---|
| 燈（預設） | 照亮別人的路 | 原本的墨 |
| 紙 | 替人擋下 | 保留的牌每回合給 2 格擋 |
| 墨 | 把人記住 | 墨到 6 時，下一張攻擊傷害加倍 |
| 線 | 不讓家人走丟 | 生命低於一半時，每回合回復 2 生命 |
| 鏡 | 看清真相，不被騙 | 敵人的偷牌、加費、塞詛咒效果，每場第一次無效 |
| 聲 | 呼喚 | 每回合第一張技能牌多抽 1 張 |
| 窗 | 替人開一條退路 | 每場戰鬥可以「放走」一個生命低於 25% 的敵人，獲得牠一半的獎勵和 1 點「燈火」 |

**燈火（克勞德專屬的善意系統）**：
- 事件裡選善良的選項（放走、分享、留給主人），或在戰鬥中「放走」敵人，就得到燈火。
- 燈火是永久累積的，會解鎖她的回憶之書、新面貌，還有只有她看得到的隱藏事件。
- 她的「其他面貌」用表情和台詞表現：害怕但不退、生氣但不傷人、哭了還是提著燈。壞選項在她的事件裡會直接灰掉，旁邊寫一句她的心聲，例如「我不要這樣。」

## 三、玩家為什麼會一直想玩
1. **每局都不一樣**：23 個型態、流派分支和混合型態，讓每局的牌組都長得不一樣。
2. **永遠有下一個目標**：還沒解鎖的型態、守燈處的強化、圖鑑、成就，每局結束都告訴玩家「離下一個還差多少」。
3. **下潛深度**：每通關一次解鎖下一級難度，共 10 級，每級加一條規則，例如精英更多、詛咒不能移除、休息回得更少。每個型態的最高深度都會記錄下來。
4. **懸疑線**：第四副碗筷、會記得選擇的事件，每局多看懂一點（文字劇情大師負責）。
5. **混合型態**：就算是老手，也會想湊齊殘響、看到那一刻的變相。
6. **每日下潛**：每天固定一組種子、型態和詛咒，全部玩家玩同一局，結束時顯示分數。

## 四、打擊感：給 Claude 的特效規格
目前缺的主要是「回饋」。照優先順序排：

| 時機 | 畫面 | 聲音 | 時間 |
|---|---|---|---|
| 打出卡牌 | 卡牌飛向目標，拖出位階顏色的光尾 | sfx_card_play，上面疊一層目前型態的音色 sfx_form_*（語嫣用世界書代號：B01、M01、M02、M03；克勞德用 lamp、paper、ink） | 0.25 秒 |
| 造成傷害 | 敵人圖往後彈、閃白，跳出傷害數字（越大字越大）；10 傷以上畫面震動，30 以上加 80 毫秒定格 | 一般用 sfx_hit，10 點以上用 sfx_hit_heavy，30 點以上用 sfx_hit_crit | 0.3 秒 |
| 獲得格擋 | 角色前方浮出半透明護盾，數字跳動 | sfx_block | 0.3 秒 |
| 給予厄契 | 一條緋紅絲線從角色射到敵人身上纏一圈 | sfx_pact | 0.4 秒 |
| 命線 | 被連住的敵人之間拉出會抖動的紅線，受傷時線會亮一下 | — | 常駐 |
| 裁定 | 紅線全部收緊、斷開，畫面暗一下再爆開 | sfx_judge | 0.6 秒 |
| 獲得墨 | 墨滴從畫面上方落到墨量表，墨量表晃動 | sfx_ink | 0.3 秒 |
| 抽到詛咒 | 卡牌邊緣像訊號不良一樣抖，畫面邊緣閃一下紫黑 | sfx_hurt | 0.4 秒 |
| 自己扣血 | 畫面邊緣紅一下 | sfx_hurt | 0.3 秒 |
| 生命低於 30% | 畫面四周常駐暗紅暈影，配心跳聲 | sfx_heartbeat_loop（loopEnd 0.833 秒，血越低 playbackRate 從 1.0 調到 1.6） | 常駐 |
| 敵人死亡 | 化成紙灰往上飄散 | sfx_kill | 0.8 秒 |
| 遺物觸發 | 遺物圖示發光放大一下 | sfx_relic | 0.3 秒 |
| 外漏升級 | 立繪的影子長出尾巴或眼睛，量表裂開一格 | sfx_corrupt | 1.1 秒 |
| 變相 | 全畫面暗下來，立繪換成型態圖，命線全亮 | sfx_transform（1.2 秒的重擊對齊立繪切換） | 1.7 秒 |
| 回合開始 | 敵人意圖圖示一個個跳出來 | sfx_turn | 0.4 秒 |

- 加一個「特效強度」設定（低、中、高），手機發熱或想快速玩的人可以關掉震動和定格。
- 連續打出 3 張以上的攻擊，在畫面角落顯示連擊數，每多一擊字更大一點，同時播 sfx_combo，每多一擊 playbackRate +0.08。
- 渡鴉巷：點地點用 sfx_door，從井口下潛用 sfx_well，用殘響換強化或解鎖用 sfx_unlock，移除詛咒用 sfx_purify。環境底噪 amb_town 和 amb_dive1～3 跟背景音樂分兩個音軌播。


## 五、v0.5.1 數值：異化值、共鳴、送回（取代第一段裡外漏和混合型態的觸發方式）

### 異化值（0～100，跨戰鬥保留）
| 來源 | 異化值 |
|---|---|
| 自己失去生命（代價牌、詛咒） | 每 1 點 +2 |
| 抽到詛咒 | +5 |
| 回合開始時生命低於一半 | +5 |
| 打出本源專屬牌（契） | +4 |
| 戰鬥結束 | -15 |
| 營火休息 | -30 |

- 30：第一階段，影子長出尾巴，攻擊牌傷害 +1。
- 60：第二階段，文字開始出錯，每回合多抽 1 張，回合開始失去 1 生命。語熙接手只會在這個階段以上出現，每場戰鬥機率 15%，持續 1 回合。
- 100：變相，見下方。變相結束後異化值歸 0。

### 共鳴（決定變相成什麼）
- 每打出一張本源專屬牌，或拿到一件殘響遺物，就得到該本源 1 點共鳴，整局保留。
- 異化值到 100 時檢查：如果某個混合型態需要的 3 個本源各有 2 點以上共鳴，就變成那個**混合型態，維持 3 回合**。每回合多 2 能量，有該型態的專屬效果，每回合結束失去 4 生命。
- 沒湊到的話，變成目前本源的**完全型態，維持 1 回合**：所有牌免費，回合結束失去 8 生命。
- 混合型態每局最多出現一次，第二次到 100 時只會變成完全型態。

### 送回（克勞德的善良機制）
- 敵人生命低於 25% 時，牠的頭上會出現一盞小燈，點一下就能「送回」。
- 代價：1 能量，再加上二選一，「失去 4 生命」或「把手上一張牌放進消耗堆」。
- 效果：敵人安靜地消失，算作打倒，獎勵照拿，另外得到 1 點燈火。首領不能送回，只有最終首領例外，劇情上有特別的結局分支。
- 七面的「窗」讓送回的門檻放寬到 35%，而且不用付第二個代價。

## 六、可解鎖的其他角色（討論用）
規則上，新角色要成立需要三樣東西：自己的資源（像厄契、墨）、一個起始牌組、一條和兩姐妹不重複的打法。建議：
- 兩位主角都通關一次之後，才開始解鎖其他角色。
- 一次只開放一位，每位約 25 張牌，先在其中一層當作 NPC 或首領登場，讓玩家先認識他，再解鎖成可以玩的角色。
- 名單請文字劇情大師從世界書挑，我再替每位設計資源和打法。尺度照目前的約定。

## 七、營地／城鎮（規則面）
主畫面改成據點「渡鴉巷」（文字劇情大師版），一張背景圖上有 5～6 個熱點；織命坊是兩人的家，每個設施對應一個規則功能：
| 設施 | 功能 |
|---|---|
| 守燈處 | 用殘響買永久強化（v0.4） |
| 更衣間 | 換本源型態和時裝 |
| 書房 | 回憶之書、怪物圖鑑、成就 |
| 委託牆 | 每局可以接 1 張委託，例如「不用治療打倒第一層首領」，完成後多拿殘響 |
| 下潛井 | 選下潛深度，出發 |
| 訓練室 | 自由打一場，用來測試牌組，沒有獎勵 |
設施會隨著帶回的殘響慢慢開放，第一次只有下潛井和守燈處。

## 八、v0.5.2 三相：人形、半妖、完全非人
每個本源都有三相，用異化值切換（取代第一段第 2 層的分級）：

| 相 | 異化值 | 戰鬥 | 戰鬥外 |
|---|---|---|---|
| 人形 | 0～39 | 正常 | 事件可以「交涉」（多一個談判選項），商店多一件商品 |
| 半妖 | 40～99 | 攻擊 +1、抽牌 +1；回合開始失去 1 生命 | 事件可以「威嚇」（用嚇的拿東西，不用付錢）；交涉選項消失 |
| 完全非人 | 100（變相） | 本源或混合型態的完全效果（見第五段） | 只會在戰鬥中出現，結束就退回人形 |

**三相牌**：每個本源的 2 張專屬牌，在三相下各有一段不同的效果，牌面插圖也會換成那一相的樣子。例如毒蛇的「纏頸」：
- 人形：給予 3 層厄契。
- 半妖：給予 5 層厄契，抽 1 張牌。
- 完全非人：給予 8 層厄契，敵人這回合不能行動。

**玩家能控制自己變成什麼樣子**：
- 新增共通牌「收斂」（1 費技能，r1）：異化值 -20，獲得 6 點格擋。想保持人形的玩家可以帶上它。
- 新增共通牌「放任」（0 費技能，r1，消耗）：異化值 +25，失去 3 生命。
- 結果會變成兩條路：一直壓著保持人形，在事件和商店裡佔便宜；或刻意放任，在戰鬥中求爆發。每個本源適合的路線不同，例如莉莉絲適合人形，蟲族和章魚適合非人。

**敵人和世界會有反應**：
- 半妖相時，部分膽小的敵人（例如紙人）會在意圖裡出現「想逃」，回合結束時有 20% 機率直接逃走（不給獎勵）。
- 有些事件的 NPC 會對不同的相說不同的話；完全非人只在戰鬥中出現，所以 NPC 只會記得「她剛剛那個樣子」。（文字劇情大師負責）

**相的紀錄**：每局結束時記錄「這局大部分時間是哪一相」，三種都用某個本源通關過，就解鎖那個本源的特殊時裝。

**喚回（v0.5.2 補充）**：完全非人結束時，異化值歸零、回到人形，這一刻叫「喚回」。畫面上出現克勞德的聲音「姐姐，看我。是我。」（台詞由文字劇情大師提供）。語嫣的局裡克勞德不會上場戰鬥，所以喚回是自動觸發的演出，不是一張牌，也不花能量。「送回」只用在克勞德放走敵人；語嫣自己壓低異化值則是用「收斂」這張牌。 音效用 `sfx_recall`（2.2 秒），台詞、背景音樂解除悶音和異化值歸零，都對在 0.9 秒。

**三相圖檔命名（給 Claude）**：人形 `y_skin_<本源>`，半妖 `y_<本源>_half`，完全非人 `y_<本源>_full`。例如毒蛇是 `y_skin_M01`、`y_M01_half`、`y_M01_full`。異化值跨過 40 和 100 時換立繪，回到 39 以下時換回人形。找不到某一相的圖就沿用上一相。

**語熙圖檔（給 Claude）**：異化值第一次跨過 60 時，全畫面閃一下 `yx_reveal` 約 0.8 秒，配上 `sfx_corrupt`。語熙接手的那一回合，立繪換成 `yx_base`；回合結束換回目前那一相的立繪。
