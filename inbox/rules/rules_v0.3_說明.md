# 渡鴉下潛 規則 v0.3 說明（暗黑詭異改版）

尺度：限 20 歲以上，以心理恐怖和「不對勁」為主。有代價、有詛咒，但不寫肢解、虐待特寫或性內容。v0.2 的 id 和數值全部不變，圖片照舊對得上。

## 一、改名
卡牌、敵人和遺物都換成詭異風格的名字，對照表在 `rules_v0.3_additions.js` 的 `rename`。數值先不動，等模擬結果出來再調。

## 二、新機制（★ 需要 core.js 加程式）
1. **fx `hurt`**：`['hurt',n]` 是打出時自己失去 n 生命，不吃格擋。說明文字寫「失去 n 生命」。
2. **fx `mhp`**：`['mhp',-n]` 是最大生命永久 -n，目前生命如果超過上限就降到上限。說明文字寫「最大生命永久 -n」。
3. **詛咒牌欄位**（t:'x'，不能打出）：
   - `onDraw:['hurt',2]`：這張被抽到時，失去 2 生命。
   - `endHand:['hurt',3]`：回合結束還在手上時，失去 3 生命。詛咒不能打出，所以每回合都會痛，逼玩家用「重寫」之類的牌把它換掉。
   - `noRemove:1`：商店和事件的「移除一張牌」都不能選它。
   - `desc()` 目前遇到 t:'x' 只寫「不能打出。」，請改成「不能打出。」後面再接上這三個欄位的說明。
4. **敵人招式 `addCard`**：v0.2 已經提過，這次多拿來塞詛咒牌，加進抽牌堆。
5. **事件 `maxhp` 負數**：現在扣最大生命時，目前生命不會跟著降，請補一句 `st.hp=Math.min(st.hp,st.maxHp)`。
6. **遺物**：眼珠鈕扣、借來的心跳、無名者的燈、撕掉一半的合照，效果寫在 `d` 裡，照 core.js 其他遺物的方式寫死。

## 三、設計想法
- **代價牌**：比同費用的牌強 30～50%，用血來換。最大生命永久扣掉的牌（最後一個結、最後一頁）都是消耗牌，一場只能用一次。
- **詛咒牌**：會一直在牌組裡跟著你，讓牌組越來越「髒」。克勞德的保留流手上本來就容易塞滿，詛咒對她特別難受，所以給了她「把字吞下去」抽牌找解法。
- **兩難事件**：每個選項都要付點什麼，沒有「白拿」的選擇。最安全的那個選項也要付一點小代價。

## 四、平衡提醒
- 「眼珠鈕扣」的 +1 能量很強，低語每場一張、抽到扣 2 血，估計一場會扣 4～6 血。如果模擬勝率太高，就改成每場加兩張。
- 「以血立契」只要 0 費，配合「生死同線」可能太強，需要看模擬。
- 詛咒加進來後整體會變難，第一層的敵人都不會塞詛咒，詛咒招式從第二層才開始出現，讓新手能打到第二層。

## 五、語嫣的本性（依設定文檔：貪心、記仇、妖物血脈、護短）
- **貪**：fx `gk`，`['gk',n]` 是這張牌打倒敵人時，多得 n 渡鴉幣。說明文字寫「如果打倒敵人，多得 n 渡鴉幣」。
- **記仇**：能力 `grudge`，每次受到攻擊傷害，攻擊者獲得 {n} 層厄契。
- **豎瞳**：能力 `beast`，生命低於最大生命一半時，攻擊牌傷害 +{n}。和代價牌一起用，越受傷越危險。
- **髮根的白狐毛**（語嫣遺物）：每場戰鬥只觸發一次。
- 「別看，妹妹」是她護短的那一面，數值照舊。

## 六、v0.3.2 平衡修正（看過 Claude 300 場模擬：語嫣 11%、克勞德 2%）
1. **以血立契**：費用維持 0，厄契 4 → 3（升級後 6 → 5）。語嫣還是比較強勢，但不會一張牌就撐起整副牌組。
2. **克勞德新卡「塗掉」**（`cl_erase`，0 費技能，普通）：把手上 1 張詛咒放到抽牌堆底，抽 1 張（升級後 2 張）。新 fx `['bury',n]`，說明文字寫「把手上 n 張詛咒放到抽牌堆底」，手上沒詛咒時只抽牌。「把字吞下去」維持扣 2 血，代價牌就該有代價。
3. **「塗掉」的出現率**：克勞德的卡牌獎勵裡，「塗掉」出現的權重 ×2，讓她在第二層詛咒出現前比較有機會拿到。
4. **首領**：兩人大多死在第 2、3 層的首領，所以第二層「千號」的生命從 115 降到 105，第三層「深挖」從 160 降到 145。第一層「無簽」不動，留給新手當門檻。
目標：模擬勝率語嫣 10～15%、克勞德 8～12%。模擬比真人笨，這樣真人老手大約會落在 30～50%。
