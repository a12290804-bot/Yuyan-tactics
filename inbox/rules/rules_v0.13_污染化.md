# 規則 v0.13：污染化（語凰嫣的無限慾望）

資料：`inbox/rules/rules_v0.13_patch.js`。核心：牌被慾望吃過就變強，但每次打都要付血、漲異化值。停下來會戒斷，越滿越空。

## 一、污染（每張牌 0～3 層，記在牌的實例上 `tn`）
| 層 | 數值 | 打出失去生命 | 異化值 | 其他 |
|---|---|---|---|---|
| 0 | ×1 | 0 | 0 | |
| 1 | ×1.3 | 1 | +1 | |
| 2 | ×1.6 | 2 | +2 | |
| 3 | ×2.0 | 3 | +4 | 停不下來：打完以後，手上如果還有污染牌，要自動打出最左邊那張，每多打一張再失去 2 生命 |
- 數值倍率乘在 d、da、b、heal、hardB 上，四捨五入。
- 只有語凰嫣的牌會污染，克勞德和顧沉舟不受影響。

## 二、牌怎麼被污染
- 打出「餵我」或「渴」這類牌。
- 每次異化值到 100（合相），隨機 2 張牌污染 +1，這個污染整局都在。
- 戰鬥裡加的污染（例如「渴」）戰鬥結束後消失；合相和「餵我」加的整局都在。

## 三、上癮的代價
- **饜**：每打出 1 張污染牌，饜 +1。
- **戒斷**：這回合一張污染牌都沒打，回合結束失去「饜」那麼多生命。
- **越滿越空**：生命滿的時候，治療改成增加等量異化值。
- **斷**：休息點的新選項。放棄回血，把 1 張牌的污染歸 0。
- 克勞德喚回時，饜歸 0。
