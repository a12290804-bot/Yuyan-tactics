### 2. 統一資料形：對齊 v0.7 第七段

v0.7 規定每一筆本源／慾望／心願／個性／癖好都是：

```js
{id, kind:'origin|desire|wish|persona|quirk', who:'yy|cl|yx|gu', img, sfx, cards, fx, lines}
```

規則欄（`fx`、`cards`）留空就只換外觀。這個骨架可以直接用。實作上建議**只加擴充欄、不改官方鍵名**：

```js
{
  id:'greed', kind:'desire', who:'yy',
  n:'貪', img:'inbox/y_desire_greed.webp', sfx:null,
  cards:null,
  fx:{goldMul:1.5, shopExtra:1, shopCorrupt:10}, // 空＝只換裝
  lines:{pick:['yy','smug','……'], yx:['yx',null,'……']},
  // 以下為擴充，不在第七段，但接現有引擎需要
  unlock:{type:'echo', at:50, need:'beat_l1_boss_once'},
  skin:'y_desire_greed',           // 語熙接手改讀 yx_desire_<id>
  swap:null,                        // 僅 origin：['b_coil',2]
  ph:null                           // 僅本源專屬牌的三相效果
}
```

**和第七段的差異、以及建議：**

- `caf414e` 原文 `who` 寫的是 `gcz`。`005d6dd` 已改成 `gu`。程式**只准用 `gu`**，不要兩套代號並存。圖檔是 `gu_base`、`gu_ex_*`、`gu_skin_*`（後兩項 v0.7 第六段尚未列出 `gu_skin_*`，但已約定，請補進規則）。

### 3. 三相牌 `ph`：仍然好接

現有 `cardDef` 只合併升級。讓 `cardDef(D,c,st)` 再合併當前相即可。資料形維持：

## 五、扇形手牌實作規格（給 Claude）

只改戰鬥 `#hand`。用 CSS transform，配 `sfx_card_lift`／`sfx_card_return`／`sfx_card_locked`。

- 取消橫向捲動，牌絕對定位、底原點，視寬內扇開。`spreadX = min(52, (視寬-24-112)/max(n-1,1))`，牌越多重疊越深。`theta` 約 3／5／6.5 度（依張數），`rot=(i-mid)*theta`，`ty=(i-mid)**2*2.8`。
- 選中或滑過：抬高、略縮小旋轉、`z-index:100`，播一次 `sfx_card_lift`。手機以點選為主（先抬起，再點敵或再點一次打出）。
- 拖曳當加強，不擋點選。沒過出牌線則彈回並播 `sfx_card_return`。鎮屍符鎖住的攻擊牌變暗、拖出彈回、播 `sfx_card_locked`；鎮屍符本身置頂。
- 保留牌加小鎖，語熙圈牌加紅圈，詛咒黑紫框加薄霧（不要對整扇做 `filter`）。
- 幾何只在張數或視寬變化時算；不要每打一張就 `innerHTML` 重繪整扇。特效低檔則幾乎平鋪、輕微重疊。
