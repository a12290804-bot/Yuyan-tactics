《語嫣・永生戰棋》v1.7.0 更新包

手機上傳順序
1. 先在 GitHub 的 inbox 資料夾上傳這一張，檔名保留：
   inbox/px_spear_blue_20514.png
2. 到 GitHub 倉庫最外層，一次上傳並覆蓋以下四個檔案：
   data.js
   index.html
   talk.js
   sw.js
3. GitHub Pages 部署成功後，遊戲標題顯示 v1.7.0。

其餘已上傳的 inbox 圖片、core.js、camp.js、sfx.js 繼續使用倉庫內版本。
上傳清單留在本機即可。現有 v0.7 的未完成戰鬥可接續，更新前可先匯出備份。

手機試玩路線
・任務日誌 → 前往議事桌 → 點兩個編號交換站位 → 出發。
・戰場先選隊伍，點敵人看威脅，再選落點看風險。
・守住南門 → 街巷找阿紉 → 解救阿渠 → 護送到南側標有「撤」的金框 → 回醫所。
・名冊 → 槿 → 棋子外觀 → 原版／藍皮長槍手。選擇會記入存檔。
・戰鬥選單可切換敵方回合逐隊播放／快速結算。
・望燈與緋厄技能插畫在開啟接戰演出時顯示。
・橫掃沿用戰場範圍演出，等對應的橫掃格圖再換。
