# 《語嫣・永生戰棋》素材庫

此目錄供正式遊戲引用；`/inbox/` 則是新素材暫存區。

## 美術圖 (`art/`)

- `heroes/` 英雄／可用角色立繪與頭像
- `enemies/` 一般敵人與小怪
- `bosses/` 領主、首領、主宰
- `npcs/` 城鎮居民與劇情角色
- `backgrounds/` 場景與劇情背景
- `icons/` 小圖示、按鈕與微型圖
- `materials/` 製作素材與通用資源圖
- `status/` 狀態、增益、減益圖示
- `terrain/` 戰棋地形、格子與地圖零件
- `equipment/` 武器、護甲、飾品
- `items/` 道具、消耗品、掉落物
- `ui/` 介面框、面板、裝飾
- `effects/` 特效原圖、粒子素材

## 音樂 (`music/`)

- `bgm/` 主題、劇情與探索配樂
- `battle/` 戰鬥與首領音樂
- `ambient/` 氛圍與場景循環聲
- `sfx/` 音效（技能、按鍵、受擊、勝利等）

## 動畫 (`animation/`)

- `heroes/` 英雄動作
- `enemies/` 敵人與首領動作
- `effects/` 技能與戰場動畫
- `cutscenes/` 劇情過場
- `ui/` 介面動態

建議檔名：`代號_用途_階段_版本.副檔名`，例如 `YUYAN_portrait_normal_v01.png`。不要覆蓋正史素材；新版本先保留，確認引用後再處理舊檔。
